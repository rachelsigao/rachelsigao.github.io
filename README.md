# Rachel Sigao — DevOps / Cloud Engineer Portfolio

Live site: https://rachelsigao.github.io

This is a static portfolio hosted on GitHub Pages.

## What is automated?

- Every push to `main` deploys the site automatically through GitHub Actions.
- The GitHub contribution snake is regenerated every day.
- GitHub Stats and Top Languages are loaded dynamically from GitHub Readme Stats.

## GitHub Pages setup

1. Open the repository settings.
2. Go to Pages.
3. Under Build and deployment, choose `GitHub Actions`.
4. Push the files in this repository to the `main` branch.
5. Open `https://rachelsigao.github.io`.

## Personal edits

Update the following in `index.html` when ready:

- Email address
- Project descriptions
- Project repository links
- Experience / learning timeline
- Resume link if you want to add a PDF

Replace `assets/profile.jpg` if you want to use a different photo.
